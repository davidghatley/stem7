01How it was made

It started as a logo

My mark is a d and an h sharing one stem, drawn on 7 × 7 cells. Its stem set the cap height, its bar set the x-height, and the rest of the alphabet had to fit around it. Type dh in Stem 7 and you get the mark back.

02The source

Drawn in a text file

No font editor. Each glyph is nine rows of X and . in a plain text file, with the reason for the drawing written above it. Diffs are readable and every argument with myself is in version control.

03The em

Eight cells to the em

The em is 2,400 units, or 8 cells of 300. So one cell is always the font size divided by eight, and at the five house sizes that comes out to a whole number of pixels.

04The test

Zero grey pixels

A crisp pixel font has two colours: ink and not ink. Any pixel in between is the rasteriser guessing. This loupe renders the font in your browser right now and counts the guesses.

05Grid

The one with gaps

Grid draws every cell as its own square, with a gap cut from the top and right. No single gap stays whole at every size, so Grid is a variable font: the gap is half a cell up to 40 px and a third of a cell from 48 px. Browsers pick it automatically.

06Revisions

Three rounds of arguing with myself

The first draft looked fine as an alphabet and fell apart in words. place read as ploce, and 64×64 had a lowercase x in the middle. Each fix below has its reason written into the source.

07Bold

Bold, by hand

The bold draft is a rule: double every column that carries a stem. That works for H and falls apart on diagonals, curves and dots. 64 of the 120 bold glyphs were redrawn by hand.

08Spacing

Kerning in whole cells

Kerning comes from the drawings, not from my eyes at 2 a.m. For each pair, compare the facing edges row by row and average the gap. Under 3 cells: leave it. 3 to 5: pull in one cell. 5 or more: two. Never closer than one cell, and never into a mouth like C's.

09Character set

Every character

Basic Latin, curly quotes, dashes, arrows, the mark and seven project glyphs. Pick one to see how it is built.

10In use

Good at small, exact things

HUDs, counters, labels, numbers that change while you watch. Figures are tabular, so they don't jiggle. Not recommended for your novel.

11Install

Get it

TTF and WOFF2 for Regular, Bold and Grid, a ready-made stem7.css and the licence. One zip, 30 KB. No account, no newsletter, no "pay what you want" guilt screen.

Download stem7.zip

<h1 class="stem7 stem7--48">Hello</h1>

Served from GitHub by jsDelivr. Paste it into your <head> and move on with your life.

HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/davidghatley/stem7@v1.0.1/stem7.css">
Or write the CSS yourself 
@font-face {
  font-family: "Stem 7";
  src: url("https://cdn.jsdelivr.net/gh/davidghatley/stem7@v1.0.1/fonts/Stem7-Regular.woff2") format("woff2");
}
.pixel {
  font-family: "Stem 7";
  font-size: 32px;            /* 16, 32, 48, 72 or 120 */
  line-height: 1;
  -webkit-font-smoothing: none;
}
  1. Five sizes. 16, 32, 48, 72, 120 px. Anything else is a blur with extra steps.
  2. line-height: 1. The baseline then sits exactly 7 cells below the top of the line, at every size.
  3. Caps and figures at 16 px. Lowercase there has an x-height of 8 pixels. It tries its best. Start lowercase at 32.
  4. Smoothing off. -webkit-font-smoothing: none on macOS. The font has nothing to smooth.
  5. Whole-pixel positions. Half a pixel of offset buys you all of the blur.
  6. Grid from 48 px up. Smaller works, but it gets thin.
